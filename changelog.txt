Version 1.00
============

Sep 20, 2026
------------
- Corrected documentation
- Corrected a bug in change_upper_bounds, module pyloa.mip.grb_mip

Oct 1, 2026
-----------
Corrected bug in procedure charalambous, module plane.center.
When finding the center for 3 points of equal weights, the
weight was ignored. This is corrected by including an optional
parameter equal to the common weight of 3 points in function
_3circle.

Oct 2, 2026
-----------
In all modules of subpackage pyloa.plane: np.inf, np.Inf, np.infty
replaced by float('inf')

Oct 19, 2026
------------
Increased depth for recursive calls in function welzl, module pyloa.plane.center.


Version 1.01
============

Oct 27, 2026
------------
Introduced functions and properties in modules pyloa.plot and pyloa.plane.plansolver
for changing the map tile server and the size of points of customer locations in map.

Oct 27, 2026
------------
Removed fatal bug in module pyloa.plane.weber_cg. I forgot to append columns (customer subset
and facility location for this set) to the list of generated columns in case that they were 
generated by solving the pricing problem.

Oct 28, 2026
------------
Include the option to set a node limit for the MIQCP solver for solving an instance
of the planar p-center or multi-source Weber problem. Additionally, an optional time
limit for the colum generation (module weber_cg) has been included.

Oct 29, 2026
------------
Included the option to solve p-center, p-median and maximal covering problems via Cplex's 
built-in Benders' decomposition (cf. property useBenders of class NetProblem).

Oct 30, 2026
------------
Replaced the loop in function chgCoeffs, module cpx_mip and grb_mip, as this is too slow.
In case of Cplex, set_coefficients is used instead to adjust all coefficients, whereas
in case of GuRoBi, the old constraint is removed and replaced by the adjusted one.
